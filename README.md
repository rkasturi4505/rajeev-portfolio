## About

This repository contains my personal developer portfolio, designed to showcase my professional experience, technical expertise, projects, certifications and engineering capabilities.

The application is built as a full-stack solution with a **React + TypeScript frontend** and a **Spring Boot + MySQL backend**, with authentication, analytics, administration and AI-powered portfolio assistance.
